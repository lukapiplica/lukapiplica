- **Linux Server Hardening & Security**
  - **Implementation:** SSH key authentication, port obfuscation, and ICMP suppression.
  - **Automation:** Set up unattended-upgrades and UFW firewall orchestration.

- **Linux Environment Customization (Dotfiles)**

- **Hardware Restoration & Modification**
  - **Optimization:** System overhaul, deep cleaning, and thermal management optimization.
  - **Firmware:** Manual firmware upgrades and system exploits for custom environments.
